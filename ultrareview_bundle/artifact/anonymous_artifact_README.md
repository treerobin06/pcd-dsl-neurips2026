# Anonymous Artifact

This is the exact directory layout used to build `anonymous-code.zip`.

```text
anonymous-code/  # code, tests, prompts, curated result JSONs
data/            # minimal datasets used by the runners
phase1/          # compatibility code and strategy-ablation summaries
```

Run commands from `anonymous-code/`; the code expects `../data` and `../phase1`
to be sibling directories.
